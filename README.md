# Kaggle Customer Churn Analysis & Prediction

## Overview

This project analyzes a customer churn dataset obtained from Kaggle to identify patterns associated with customer attrition and build a machine learning model capable of predicting customer churn.

The project demonstrates an end-to-end data science workflow including data ingestion, preprocessing, exploratory data analysis, visualization, machine learning, model evaluation, and version control using Git.

## Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Git
- GitHub
- Kaggle Datasets
- VS Code

## Project Workflow

1. Imported customer data from a Kaggle dataset
2. Inspected dataset structure and data quality
3. Handled missing and invalid values
4. Performed descriptive statistical analysis
5. Analyzed customer churn distribution
6. Encoded categorical features for machine learning
7. Split data into training and testing datasets
8. Trained a Random Forest classification model
9. Evaluated predictive accuracy and classification performance
10. Identified the features most strongly associated with customer churn
11. Generated visualizations of analytical results
